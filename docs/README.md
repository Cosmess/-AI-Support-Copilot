# Documentation

Pasta canônica de documentação do projeto.

## Estrutura

- `product/`: requisitos e escopo
- `architecture/`: visão arquitetural e decisões técnicas
- `adr/`: Architecture Decision Records
- `runbooks/`: operação e incidentes
- `quality/`: avaliação RAG, riscos e segurança
- `diagrams/`: diagramas Mermaid

## Nota

A pasta `SDD/` foi mantida temporariamente por compatibilidade, mas a referência oficial passa a ser `docs/`.
