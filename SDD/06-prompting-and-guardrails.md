# 06. Prompting and Guardrails

## Prompt contract

- Papel: analista de suporte técnico sênior.
- Regra: usar apenas contexto fornecido.
- Falta de dados: declarar ausência de evidência.
- Formato de saída: estruturado em seções.

## Guardrails implementados

1. Prompt restritivo com escopo explícito.
2. Saída parseada para estrutura final.
3. Fallback quando não há dados externos.

## Próximos guardrails recomendados

1. classificação de risco de resposta;
2. validação semântica de evidências;
3. redação de dados sensíveis automaticamente.
